主な実績

  • アプリ内アンケート機能
    要望収集の方法を調査・提案して要件を固め、アプリ・サーバー双方を実装してリリース。アプリだけでなくサービス自体への意見も届くようになった
  • プッシュ通知基盤の改善
    DB 管理の送信キューを SQS（DLQ 併用）へ移行し、大量配信時の DB 負荷とリトライ自前実装の課題を解消
  • お知らせ機能
    スプレッドシートの入力内容がそのまま反映される仕組みを構築し、運用者だけで掲載・配信が完結
  • 開発プロセス整備
    OpenSpec による仕様駆動開発で、誰が実装しても同じフローになるモバイルチーム向けの進め方を整備
  • 在庫管理システム
    要件定義・画面設計・DB 設計を担当し、スケジュール通りにリリース
